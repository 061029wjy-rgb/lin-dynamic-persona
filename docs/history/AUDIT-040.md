# 基线审计及开发决定
起点：用户提供的 lin-dynamic-persona-4.zip，manifest 0.3.0。原包不变；原样静态检查和 53 项基线用例通过。
|0.3.0 实际行为|0.4.0 目标与检验|
|---|---|
|规则可以将匹配的典型故事写入长期人格|纯本地只记录可核对的文本和手工决定；正反例都不得自动长出 L1|
|32 维词表、可选外部 Embedding|移除这两条执行路径；中文分词及 n-gram 倒排 BM25；按分支/知情过滤后计算分数|
|模型产出经 applyAnalysis 直接进入状态|先核验原文位置、主体与权限；事件候选、主观评价、提案、批准人格分开|
|渲染后延时 600ms 即认为保存|后台读 ST 的已保存版本，比对选中链；失败跳过|
|静默恢复可能放行不符的快照|无可信对应就暂停；手工选择必须属于当前历史|
|遍历每楼、复制整份状态，生成前可能等待数据库／检索 API|后台准备分支索引与投影，生成时只做身份核对、少量文本检索和一次注入|

四参数拦截器由宿主调用；分析复用当前连接的 generateRaw；其公开签名不接收独立 AbortSignal。不能为“取消分析”停止用户的主生成，更不能在后台无限重试。摘要仅作导航，原文存在也只能证明说过这些字。缺乏可靠的事件时间时，不用重复提及次数来代替独立证据。局部高信任默认不启用。情绪演出不是既成剧情。去除必填变量；原有手动变量作为可选笔记保留。
