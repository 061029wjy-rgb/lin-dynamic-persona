宿主：SillyTavern.getContext、四参数 interceptor、单个系统槽、等待已存聊天；不依赖 QUICK_RESTORE。TauriTavern 的 Rust 后端不加载 ST 的 Node 插件，需部署到可信远端网关或使用直连/主模型。真实 Google 模型接收情况不能由本地记录保证。
分析合同：仅发已知人物/获准的消息及受限上下文，输出带引文的事件、主观解释、提案、导航；允许无变化。演出合同：只写可用的心理、权衡或目标，最多四行，可内隐；原文、原始分析 JSON 与用户秘密不直接拼入。
鉴权：ST 走现有连接；OpenAI/DeepSeek/OpenRouter 走 Chat Completions；AI Studio 用 key；Vertex 用服务端 ADC OAuth；Anthropic Messages、Ollama /api/chat 分别使用各自协议。外部配置的具体目标、模型变更需要重新授权。OpenRouter 禁用失败切换不等于锁定首选；要求确定供应商时明确锁定唯一 provider。
不设自动探测后计费重发；无实机、无独立盲评的项目只记录证据等级，不能把自造故事算作独立测评。迁移保留旧快照；升级不继承自动扣费许可。
