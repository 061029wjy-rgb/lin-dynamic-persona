# 设计、分期与验收映射

本实现依据用户在聊天中提供的需求文本；没有收到另述的完整 Markdown 附件。以下 P0/P1/P2 是把已收到需求分解后的实际交付阶段，不冒充未知附件中的原分期。

## P0：可安装与状态正确性

- manifest + ESM 入口 + 中文面板，无构建和运行时包依赖。
- `model.js`：四类后天影响；原始卡只读输入。状态持续与表达方式分离，按本人回复计时。
- `storage.js`：账号隔离的 IndexedDB，streams/nodes/vectors 三张表；事务与修订号防止过时页面覆盖新编辑。
- `timeline.js`：owner 为群组/角色与聊天 ID；metadata 的 stream 只作源快照定位。新 owner 使用新 stream。链式 SHA-256 指纹只处理当前可见故事与发言者；不把思考链或选项序号作为剧情。
- 冻结、禁用、人工管理、删除屏蔽、有限修订回退。
- 分支、Swipe、重新生成、编辑、删除与回档从共同前缀重建。子节点记录 parentRevision，父节点人工改变后不会继续加载过时子状态。

P0 首批纯核心测试 3 项通过后继续扩展；最终测试套件增加数据库与完整分支路径。

## P1：有证据的长期演化与检索

- `analysis.js`：原始人格 + 已知剧情的有序批次 + 已有倾向 + 检索经历 → 独立模型 JSON → 严格校验 → 原子应用。
- 事件有 subject/appraisal、逐字 source 和角色知情范围；候选自动变化必须至少引用当前批次的有效新证据。
- create/revise/retire 分别允许形成、强化/削弱/修订、消退。没有固定好感阈值或“次数达到就转化”的规则。
- 自我认知 selfView 与实际行为 behavior 分开。短期/即时寿命根据事件后已经过去的本人回复校正。
- 删除屏蔽记录整条来源节点，换概念/换摘要不能绕过同一证据屏蔽；禁止沉淀按来源节点交集判断。
- `retrieval.js`：先做分支和知情权限检查，再进行中英文关键词、时间、显著性与向量混合排名。向量缓存含 stream、actor、model、内容 hash；失败降级。
- 群聊不因两人在同一聊天就假定共享全部信息。授权是逐条消息、逐个角色；分析提示进一步约束全知叙述/内心独白。

## P2：生成兼容、恢复与交付

- `controller.js`：单独的本地操作队列、生成事务与取消 epoch。后台分析写回必须匹配节点 key + revision + 当前 owner + epoch。
- interceptor 最多等待本地准备 450ms；不会把模型分析/Embedding 网络请求放在生成必经路径。仅一个固定扩展提示槽位，不接管 fetch。
- 停止、工具调用、空文本、quiet、dry-run、impersonate 不写有效回复；流式 ENDED 先于 RENDERED 的顺序得到覆盖。
- 续写同一消息保留原计数；已保留的引用若仍存在于正文，重定位到新 hash。
- 恢复选择包括恢复匹配状态、重建、停用、取消；取消不影响宿主聊天生成。弹窗可关闭，关闭后只用匹配/共同前缀。
- 旧插件协作/接管/暂停三模式，接管时要求旧插件先停用，避免重复抽签；不更改其他插件设置。
- 备份严格版本校验，验证所有节点后单事务写入新的命名空间；向量可重建，不随备份导出。

## 数据路径

```text
只读角色卡 ────────────────┐
当前分支的已授权剧情 → 独立分析请求 → 引文/权限校验 → 当前节点的人格状态
                           ↑                ↓
                  合法历史经历检索     人工编辑 / 屏蔽 / 回退
                                            ↓
                                层级与范围过滤 → token 预算 → 单槽位注入
```

状态节点包含 influences、experiences、blocks、processed、grants、world、turns、disabled。nodes 保存完整快照，便于审计和确定性恢复；代价是很长剧情的磁盘占用较高。目前不静默淘汰证据或历史快照，以免回档缺失。IndexedDB 空间不足时停止本轮人格操作，正常生成继续；可导出后由用户管理站点空间。

## 已知实际限制

1. 本地 IndexedDB 不跨浏览器同步，必须单独备份。
2. 官方 saveChat 无可靠成功返回；根据最终有效正文确认本地状态，服务端保存失败无法由公开事件完全解决。
3. 原生 generateRaw 无外部 signal；旧请求取消的是写回资格，独立接口则可 abort 网络。
4. 当前场景标签与世界时间由玩家显式维护；不猜测现实时间等于剧情时间。
5. 语义后台结果在已授权同分支内复用；新消息会先用关键词降级，避免网络阻塞生成。
6. 不声称官方支持所有第三方“快速恢复”按钮；事件检测 + 每次生成前一致性检查兜底。
7. 前台提示预算小于最小完整资料块时可留空；提示词不保证模型表现出每个状态。
