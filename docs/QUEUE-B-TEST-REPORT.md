## 原测试调整说明

`tests/services.test.js` 的测试数量和实质断言保留。`scheduleAnalysis` 现在返回事务完成的 Promise，测试必须 await。原直接改内存 Set 的新增楼层改用 `appendQueueAnchors`。T04/T05 的时间到期和故障状态通过测试文件内专用事务注入，生产 `Database.put` 仍禁止裸写。120 锚点测试仅关闭模拟调度，避免其虚构楼层在断言前被当作已不存在的分支来源退休；数量、最早锚点、背压及第二角色等待断言未删除。

旧 visible-text 分区的 `conserved` 改为 `partitionComplete`，不再承担来源守恒证明；真实守恒检查读取 `auditQueueLedger`。保留旧来源分区数量断言并增加负对照：主动破坏 queue 成员后必须 `ok=false` 且指出缺失 ID。
