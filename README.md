# Lin Dynamic Persona

面向 SillyTavern 的动态人格扩展，让角色的心理状态能够随经历变化，同时保留自己的判断、目标和生活。

## 当前版本

**0.7.0 · A+B 整合源码测试版**

A、B 已整合在同一套源码中，无需分别安装。包含完整前端、可选 gateway 源码、测试和开发文档。

- A 阶段：来源账本、队列存储、租约、原子提交及迁移保护。
- B 阶段：调度、分析请求、失败重试、队列恢复及 Inspector 接入。

## 以下是原版 0.6.0 的功能与安装说明（历史资料，不用于部署本开发构建）


这是 SillyTavern 的独立前端扩展。角色可以既感到释然，又舍不得结束合作；一时羞愧也不表示愿意道歉。插件将这些变化保存在**当前人物、当前聊天分支**，不向角色卡、世界书、预设或对话正文写入状态。无需向量、变量、第二个账号或猴油脚本。

## 安装

1. 先在旧插件面板导出人格库 JSON。旧插件文件也留一份。
2. 解压 **lin-dynamic-persona-0.6.0.zip**，用内含的 `lin-dynamic-persona` 文件夹替换旧的**同名扩展文件夹**。单用户常见位置为 `SillyTavern/data/default-user/extensions/lin-dynamic-persona/manifest.json`，多用户改为自己的账号目录；全站安装可用 `public/scripts/extensions/third-party/`。不要套两层同名文件夹，也不要同时启用两份人格插件。普通前端无需 npm。本构建未发布到 GitHub。
3. 刷新酒馆，打开角色聊天，在扩展设置展开 **Lin Dynamic Persona · 动态人格 v0.6.0**。首次核对已保存的选中分支可能需几秒。若提示不匹配，打开「恢复」查看原因。
4. 不启用 AI 也能创建、编辑、冻结和撤销心理状态。可在「创建影响」建立一个即时感受，生成一次，再从「分析预算与日志」查看该轮选入、跳过原因（含 `blocked_reason`）与字段投影对照（`fieldAudit`）。

## 可选：让人格随经历变化

在「副 API 与自动成长」选日常分析档。想用已有模型，选「酒馆当前模型」即可。使用外部服务时，先选协议、填实际模型和认证方式，勾选授权；可先看本地发送预览。**连接测试、沙盒、第二意见和每批分析都是独立请求。** 默认 AI 与自动分析均关闭；关闭 AI 不会关闭既有人格。失败不会改走主模型，也不自动重发（注：若请求已发出后断网或超时，远端服务商可能已计费；插件只保证无用户授权不自动重发、本地最多提交一次）。

- **A 手工审阅**：全进提案箱。
- **B 自动保守**：清晰、有本人原文依据的低风险感受或计划可采用，新长期人格待审。
- **C 自动成长**：明确开启后才允许有独立依据、通过基线检查的长期变化自动采用。有反证、言行不一观察或归因不清仍需审阅。选完整合同才分析 L1–L4；小模型精简合同只提议自述的即时感受。
- 可手动「分析一批」或优先分析最近片段。需要后台学习时再开「在有效回复保存后自动排队」。队列按最早未完成顺序逐批分析并仅确认（ACK）已核验覆盖的来源，超过 100 条锚点或超出并发角色上限时启用无损背压保护，绝不静默丢弃旧剧情。
- 与 `lin-emotional-control` 共存时，旧插件负责随机演出；本插件仍可提示短期心理、即时感受、长期倾向和目标。无需修改旧插件。也可以只用本插件，并选择独立抽样或仅成长。

只有需要**服务端代管密钥或 Vertex ADC** 时才安装独立的 `lin-persona-gateway-0.6.0.zip`。它不是第二份前端。Tauri 没有 ST 的 Node 插件加载器；可用酒馆当前模型，或连接自己管理的 HTTPS 网关。iOS/Tauri 与付费云渠道尚未实机验收。
